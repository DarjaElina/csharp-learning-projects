# Learning C#

A collection of small learning projects and console applications created while completing the [Foundational C# with Microsoft Certification](https://www.freecodecamp.org/learn/foundational-c-sharp-with-microsoft/) course by [Microsoft Learn](https://learn.microsoft.com/en-us/) and [freeCodeCamp](https://www.freecodecamp.org/).

## Projects

### 1. Student GPA Calculator

A simple console application that calculates a student's GPA from course grades and credit hours.

### 2. Student Grading

A console application that calculates the average grade for multiple students from their assignment scores.

**Concepts**: variables, numeric types, arithmetic operations, type casting, string interpolation.

### 3. Student Grading — Iteration & Extra Credit

Extended versions of the Student Grading project with arrays of scores, letter-grade calculation, and extra credit.

The project evolved through several guided-project versions as new C# concepts were introduced.

**Concepts**: arrays, foreach, nested iteration, conditional logic
