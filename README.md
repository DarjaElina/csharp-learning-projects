# Learning C#

A collection of small learning projects and console applications created while completing the [Foundational C# with Microsoft Certification](https://www.freecodecamp.org/learn/foundational-c-sharp-with-microsoft/) course by [Microsoft Learn](https://learn.microsoft.com/en-us/) and [freeCodeCamp](https://www.freecodecamp.org/).

## Projects

### 1. Student GPA Calculator

A simple console application that calculates a student's GPA from course grades and credit hours.

### 2. Student Grading

A console application that calculates the average grade for multiple students from their assignment scores.

**Concepts**: variables, numeric types, arithmetic operations, type casting, string interpolation, arrays, `foreach`, nested iteration, conditional logic.

### 3. Medication Time Tracker

A console application that adjusts a medication schedule when changing between GMT time zones.

**Concepts**: arrays, methods, loops, conditionals, type conversion, string manipulation.

### 4. IPv4 Address Validator

A console application that validates IPv4 addresses by checking their structure, leading zeroes, and value ranges.

**Concepts**: arrays, string splitting, methods, loops, validation, parsing.

### 5. Fortune Teller

A small console application that generates a random fortune based on a randomly generated luck value.

**Concepts**: arrays, random numbers, methods, conditional expressions, loops.

### 6. PetFriends — Pet Adoption Management

A menu-driven console application for managing information about pets available for adoption.

The application supports adding pets, validating and completing pet information, displaying pet records, and searching dog descriptions by characteristics.

**Concepts**: multidimensional arrays, `switch` statements, loops, methods, input validation, string manipulation, searching and sorting.

### 7. Petting Zoo

A console application that randomly assigns animals from a petting zoo to groups visiting from different schools.

**Concepts**: arrays, multidimensional arrays, methods, loops, randomization, optional parameters.

### 8. Console Food Game

A small console game where the player moves around the screen and consumes randomly generated food that changes the player's state.

**Concepts**: arrays, methods, loops, conditionals, `switch`, optional parameters, random numbers, console input/output, cursor positioning.
